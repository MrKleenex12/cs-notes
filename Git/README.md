## Source of truth

My notes are heavily based on [Git's Learn Page](https://git-scm.com/learn) and
[Git Docs](https://git-scm.com/docs). I give credit to such a helpful learning
page. The terminal also contains guides and docs. 

## Quick help

Type in the terminal:

- `git help <command>` to pull up documentation on a command.
- `git help` to pull up a cheatsheet of commands.

I encourage everyone to spend time learning these resources to get a thorough
understanding.
