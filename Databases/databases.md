# Databases

Why learn about databases? Databases are important for storing data. Any data that you need in the future needs
to be stored somewhere. Learning about databases will help you decide what database you need for the work you
are doing.

## What is a Database?

It is simple. A database is an organized collection of data. It uses a **database management system (DBMS)**.
A DBMS is a software that interacts with end users, applications, and the database itself to capture and analyze
the data. It also additionally encompasses the core facilities privided to adnminister the database.

Think of **databases (dbs)** as computerized indexcards that hold information. Small dbs can be stored on a file
system. Larger databases are hosted on computer clusters (multiple computers working as one system) or cloud
storage (stored somewhere that can be accessed by the internet).

## What is a Database Model

A database model is a data model (structure of data) that determines the logical structure of a database. It
determines how data is stored, organized, and manipulated. One of the most popular models are Relational and
Document. These are often called "SQL" and "No-SQL" databases respectively.
[Relational Databases](relational.md) and [Document Databases](document.md) explain in more detail.

## Components of a Database

Databases consist of several critical components that work together to store, organize and retrieve data
effectively. Here is a detailed explanation of each component:

**Data**: The actual information stored in the database, such as text, numbers, images, or files.

**Schema**: The structural blueprint that defines how data is organized—tables, fields, data types,
and relationships.

**DBMS**: The software that manages database operations like storage, retrieval, and security
(e.g., MySQL, Oracle).

**Queries**: Instructions (usually SQL) used to retrieve or manipulate data within the database.

**Users**: People or systems that interact with the database, each with specific roles and access permissions.
