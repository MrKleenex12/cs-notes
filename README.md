# Computer Science Notes

This repository tracks my notes and understanding on various CS topics.

My goal is to learn any CS topic properly instead of memorizing. I don't want
to be stuck my whole life understandning at an intern level. I want to
understand things like a senior developer. A rule I am setting for myself is
to not take shortcuts. Taking shortcuts would be disingenuous to my goal.

I also want to learn **how to learn** because I know I will never know
everything. My brain only has so much capacity (I am also not God). There is
also too much going on in my life to reach unlimited knowledge. Therefore, I
want to learn to **learn efficiently** while not taking shorcuts.
